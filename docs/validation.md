Проверки выполняются над проектными контрактами; серверная реализация в лабораторную №3 не входит.

- Redocly CLI: `npm run lint` — все 5 спецификаций валидны, 0 ошибок, 0 предупреждений (Redocly CLI 2.72.1).
- Проверка примеров и согласованности: `npm run check` — 26 операций, 7 событий и 255 примеров прошли проверку JSON Schema; проверены ссылки, единая модель ошибок, пагинация, идемпотентность, XML/SVG/PNG.

Для завершения открыть https://editor.swagger.io/ и импортировать по очереди пять файлов api/*-service.yaml через File → Import file; проверить отсутствие Errors. Линтер не считается заменой этой проверки.
